# Nitro Windows Gamer Web v0.2

Ambiente inspirado no Windows 7 para Chrome Android. Inclui demonstrações WebGL 2, WebGPU com fallback, controles de toque/gamepad e importação de HTML5 autossuficiente. Não é Windows real nem executa EXE.

## Publicação
Settings > Pages > Build and deployment > Source: GitHub Actions. Depois execute o workflow Deploy Nitro Windows em Actions ou envie um commit para main.

Endereço esperado: https://marcelofreitasferreira.github.io/Nitro-Windows/

Requer HTTPS para WebGPU e PWA. Testes em dispositivo Android real ainda pendentes.
